# Smashkov Training

A phone-first PWA for workout and weight tracking. All data stays in your browser (IndexedDB).

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173). If `node -v` shows v6, put Node.js first on PATH:

```powershell
$env:PATH = "C:\Program Files\nodejs;" + $env:PATH
```

## GitHub Pages

After the first push to `main`, enable Pages in the repo: Settings → Pages → Source: GitHub Actions.
